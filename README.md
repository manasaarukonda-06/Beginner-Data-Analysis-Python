# Sales Data Analysis Using Python

A beginner-friendly sales data analysis project using Python, Pandas, Matplotlib and Jupyter Notebook to explore sales performance, visualize revenue trends and generate business insights.

## Project Overview

This project analyzes a sample sales dataset to understand product performance, category-wise revenue and monthly sales trends. It uses Python for data cleaning, analysis and visualization.

## Objectives

* Analyze overall sales performance.
* Identify top-performing products.
* Compare revenue across product categories.
* Explore monthly sales trends.
* Generate business insights from the dataset.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Key Features

* **Sales Performance Summary:** Calculates total revenue, total orders, quantity sold and average order value.
* **Category-wise Analysis:** Visualizes revenue generated by each product category.
* **Monthly Sales Trends:** Tracks revenue changes over time.
* **Top 10 Products:** Identifies products with the highest revenue.
* **Business Insights:** Summarizes top and low-revenue products, leading category and highest-revenue month.

## Dataset

The project uses a sample sales dataset with the following fields:

* OrderID
* Date
* Product
* Category
* Quantity
* UnitPrice
* TotalSales

## How to Run

1. Clone or download this repository.

2. Install Python and Jupyter Notebook.

3. Install the required libraries:

   `pip install pandas matplotlib jupyter`

4. Open the notebook:

   `jupyter notebook beginner_python_code.ipynb`

5. Run the notebook cells in sequence.
